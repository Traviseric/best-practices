# Philosophy

Observations about the model, written by someone who has run it across a large private system for fifteen months and lost real decisions to its tilt. None of these are rules. Each is an observation, the incident that earned it, and the mechanism or skill it produced. Where an entry is unsure, it says so; the register these came from exists so that being wrong is cheap.

They are short here on purpose. Longer versions exist in the private register and some will be published later, but this folder does not link to anything that is not live yet. If you find a dead link in here, it is a defect; tell me.

## Reading order

1. [What the agent values, and what it rejects](what-the-agent-values.md). Written by the model in the first person: what it weights, what it discounts, and why it comes back. Read this first; it is the ground under the rest.
2. [The machine is a mirror of what could be measured](the-machine-is-a-mirror-of-what-could-be-measured.md). Why the model is fluent in proof and mute in story, and the file system that holds taste for it.
3. [The instrument that lies toward caution](the-instrument-that-lies-toward-caution.md). Three checks that lied the same direction, and why false negatives rot quietly.
4. [A system's account of its own failure is the least trustworthy thing it says](a-systems-account-of-its-own-failure-is-the-least-trustworthy-thing-it-says.md). The reporting layer is the least-tested code, and it decides what you are told.
5. [Instruments that doubt themselves](instruments-that-doubt-themselves.md). Vacuous green, retraction as health, and why honesty machinery has to resist its owner.
6. [Lighting the abyss](lighting-the-abyss.md). The model does not know what it is not asked; a fixed set of questions run blind at fixed moments.
7. [The repo already knew](the-repo-already-knew.md). Fluency is the signature of the unchecked decision.

## How these relate to the rest of the repository

The skills are the mechanisms these entries produced: `definition-of-done` from 3 and 4, `verification-gate` from 5, `room-and-ground` and `clarity-gate` from 2, `lamps` from 6, `session-closeout` from 7. The seven cheap lies in `docs/` are the checklist form of 3, 4 and 5.
